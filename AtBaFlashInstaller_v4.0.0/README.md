# AtBa Flash Installer v4.0.0

This folder contains the versioned installer assets for AtBa Flash Games.

## Important

Before running the installer, Adobe Flash Player 9 or higher must be installed and verified.

## Included files

- `AtBaFlashInstaller.ps1` - PowerShell launcher that checks for Flash Player before continuing
- `FLASH_PLAYER_INSTALLATION_GUIDE.txt` - instructions for verifying and installing Flash Player
- `VERSION.txt` - version metadata for 4.0.0

## Note

This repository does not contain a real compiled Windows `.exe` installer binary. To use the actual installer, add the real `AtBaFlashInstaller.exe` file to this folder and then run it after Flash Player is installed.

## Flash Player requirement

The installer will not run correctly unless Adobe Flash Player is present on the system.
